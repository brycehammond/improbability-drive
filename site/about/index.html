What is this?

The Infinite Improbability Drive was a means of crossing vast interstellar distances in a mere nothingth of a second, with the side effect that wildly improbable things happened on arrival. This is a website that does the second part only.

Press the button and the Drive invents something that has just, against all odds, occurred, then calculates those odds with the seriousness of a 1978 laboratory instrument. Or describe something you are hoping for, and it will tell you, kindly but precisely, how unlikely it is.

The reports are written by a language model working from a set of hand-written instructions about voice, and every one is kept on file so a link to it will keep working. Nothing about who pressed the button is recorded.

Mostly harmless.
